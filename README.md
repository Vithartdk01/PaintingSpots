# Painting Spots


Unleash the hidden colors of your favorite images and watch them come alive as a playful mosaic of spots! Painting Spot is a Python project that extracts dominant colors from a spot image and creates a visually appealing display: 10x10 colored spots appear randomly on a 500x400 pixel screen, each spot colored from the palette extracted from your chosen image. This project is perfect for exploring color extraction and basic graphical displays in Python.

## How it works?
Upload your favorite image, and Painting Spot will extract its most beautiful colors. Then, it randomly scatters 100 colorful spots across the canvas, each one a surprise from your image’s palette. Every run is unique—no two paintings are ever the same!
